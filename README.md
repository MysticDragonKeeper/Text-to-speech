# 🔊 Text-to-Speech Web Application

A Python-based web application that converts written text into spoken audio through a simple, accessible interface.

This project is being developed as part of my IT and software development portfolio to demonstrate practical experience with Python, web application development, APIs, user interface design, and Git/GitHub workflows.

## 🚧 Project Status

**Currently in development**

The project is being built incrementally, with features and documentation added as development progresses.

## ✨ Planned Features

- Convert user-entered text into speech
- Generate playable audio from text
- Simple and responsive web interface
- Adjustable speech settings
- Input validation and error handling
- Accessible controls and interface
- Download generated audio
- Mobile-friendly design

Additional features may be added as the project develops.

## 🛠️ Technologies

The application is being built with:
